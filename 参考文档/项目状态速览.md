## 二、代码结构

| 文件 | 职责 |
|---|---|
| `common.h` | 类型别名 u32/i32/u8、`Op::` 常量（OP_IMM/OP/LUI/LOAD/STORE/BRANCH/JAL…）、`bits()`/`signExtend()`/`regNum()` |
| `CPU.h/.cpp` | 单周期取指-译码-执行；`step()`/`run()`/`reset()`；只读接口 `pc()/reg()/mem()/finished()/inst()`（inst=最近执行的指令，给界面高亮用） |
| `Assembler.h/.cpp` | 汇编文本 → 机器码；`#` 注释；访存语法 `lw rd, imm(rs1)` 拆括号 |
| `Memory.h/.cpp` | 1MB 字节寻址，小端；`loadWord/storeWord/loadByte/storeByte…` |
| `RegisterFile.h/.cpp` | 32 寄存器，x0 恒 0 |
| `main.cpp` | 入口，创建 MainWindow |
| `mainwindow.h/.cpp` | 全部界面（队友重构） |

## 三、指令（帮助弹窗口径 19 条）

算术 `add sub addi`｜逻辑 `andi ori xori`｜移位 `slli`｜比较 `slti sltiu`｜高位 `lui`｜分支 `beq bne`｜跳转 `jal`｜访存读 `lw lb lh`｜访存写 `sw sb sh`

（CPU.cpp 里额外有 `sll/srl/or/and/xor/srli` 的 case，但汇编器还没同步，暂不算。）

## 四、界面功能

- 菜单栏：文件（新建/打开/保存/另存为/退出）、模拟器（运行/单步/暂停/重置）、视图（显隐三面板/清日志/刷新）、帮助（19 条指令弹窗/关于）；
- 按钮：单步/运行/暂停/重置/帮助 + PC 标签 + **速度输入框（0.2~50 条/秒，直接填数字）**；
- **运行 = QTimer 每拍一条**（`onTimerTick`），灯效可见；暂停 = 停 timer；
- **灯只见最后一条的坑已修**：`update()` 只排队重绘、连续几拍会被 Qt 合并 → 改成 `repaint()` 立即绘；顺带去掉每拍 new QTableWidgetItem（改复用单元格）；
- 每拍写日志 `[序号] 助记符`，图顶部显示「第 N 拍：指令（PC → 0x..）」，灯有没走一目了然；
- 内存表动态 `setRowCount(code.size())`；try/catch 已覆盖 load/step/run。

## 五、数据通路图（单行结构）

```
        ┌─────── 跳转/分支（虚线，beq/jal 亮）───────┐
        ▼                                          │
      ┌────┐  ┌────────┐  ┌────┐  ┌──────┐  ┌───┐  ┌────────┐
      │ PC │─▶│指令存储│─▶│译码│─▶│寄存器│─▶│ALU│─▶│数据存储│
      └────┘  └────────┘  └────┘  └──────┘  └───┘  └────────┘
                                     ▲        │        │
                                     └── 写回 ─┴────────┘
```

- 6 个部件一行排开，盒宽随窗口自适应（80~130px）；写回总线走下方，PC 回路走上方虚线；
- 顶部显示「第 N 拍：addi x1, x0, 5（PC → 0x00000004）」；
- 高亮 = `StageFlag` 位掩码（PC/IF/ID/REG/EX/MEM/WB/PCWR 各一位），`datapathMask()` 按 `cpu.inst()` 的 opcode 算；
- 映射：运算=REG+EX+WB；load=REG+EX+MEM+WB；store=REG+EX+MEM（无 WB）；branch=REG+EX+PCWR；jal=WB+PCWR；寄存器堆在读或写回时都亮。
